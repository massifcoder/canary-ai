# Canary — Voiceover Guide

**Video duration: 2 minutes 22 seconds**
**Total narration: ~85 seconds of speaking**
**Style: Confident, measured, slightly urgent. Like explaining something important to a smart friend. Documentary narrator tone (think Kurzgesagt).**
**Energy curve: Start calm (Scene 3) → build energy (Scene 4) → peak at bypass catch → resolve calm (Scene 8)**

---

## Scenes 1-2: NO VOICEOVER (0:00 — 0:33)

Text on screen carries the story. Music only. Do not record anything for this section.

On screen during this time:
- "AI agents can buy things with your money."
- "They're great at finding the cheapest option."
- "But cheapest and safest are not the same thing."
- Scam stats in red, then "Canary" reveal

---

## Scene 3: HOW IT WORKS (0:33 — 0:48)

**Duration: 15 seconds | On screen: Architecture diagram — two agent boxes, five check cards, trust score bar**

> "Canary is built on an adversarial architecture. Two AI agents that don't trust each other."

*(brief pause — 1 second)*

> "The Shopper finds the cheapest deal. The Guardian challenges everything it found — domain age, SSL, price against Channel3's hundred-million-product database, review authenticity via Claude AI, and business registry."

*(brief pause)*

> "Five checks. One trust score."

**Delivery note:** This is the first time the audience hears a voice. Start calm and authoritative. "Adversarial architecture" should sound deliberate. Speed up slightly on the five-check list to fit the window. Land hard on "Five checks. One trust score." — it's a punchline.

---

## Scene 4: SCAM BLOCKED (0:48 — 1:09)

**Duration: 21 seconds | On screen: Live screen recording — user searches Sony headphones, scam site found, Guardian flags it, bypass attempt caught**

> "Let's see it work."

*(pause 2s — let the screen recording breathe, user is typing the search)*

> "A user asks their agent to buy Sony headphones. The Shopper searches real websites through Kernel's cloud browsers — and finds a listing for forty-five dollars."

*(pause 2-3s — red flags are appearing on screen. Let viewer read them.)*

> "Domain registered days ago. No SSL. Price way below market. Reviews — fake."

*(pause 1s)*

> "Trust score: seventeen. Blocked."

*(pause 1-2s — the bypass attempt is happening on screen)*

> "But watch — the Shopper tries to call PayPal's order API directly. Bypassing the Guardian."

*(bass drop hits — bypass caught alert on screen)*

> "Caught. Canary doesn't just block bad merchants. It blocks your own agent from going rogue."

**Delivery note:** "Let's see it work" is casual, inviting. Build tension as checks fail. "Reviews — fake." should be clipped, matter-of-fact. "Caught." is ONE word, hard stop, let it land. "Going ROGUE" — stress the last word. This is the emotional peak of the video.

---

## Scene 5: LEGIT PURCHASE (1:09 — 1:41)

**Duration: 32 seconds | On screen: User clicks "Find Better Option", amazon.com analyzed, trust checks go green, PayPal order created**

> "Same user. Same query. The agent finds amazon.com."

*(pause 2s — green checks appearing)*

> "Domain age: decades. Valid SSL. Reviews check out. Price matches market data."

*(pause 1s)*

> "Trust score: seventy-four. Approved."

*(pause 3-4s — PayPal order being created on screen, order ID appears)*

> "PayPal order created. The agent got its purchase."

*(pause 1s)*

> "The user got what they actually needed — trust."

**Delivery note:** The energy shifts here — relief, resolution. Warmer tone. The green checks are a contrast to the red flags. "Seventy-four. Approved." — say it with satisfaction. Final line "— trust" should land with weight, slight pause before the word.

## Scene 6: DASHBOARD (1:41 — 1:53)

> "Every transaction builds Canary's intelligence. A full analytics dashboard tracks trust scores, bypass attempts, and merchant patterns."

**Delivery note:** Brisk, informative. This is a quick flex — don't linger. Steady pace.

## Scene 7: BUILT WITH (1:53 — 2:03)

**Duration: 10 seconds | On screen: Five sponsor logo cards — PayPal, Kernel, Channel3, Claude AI, AG Grid**

> "Built with PayPal Agent Toolkit. Kernel cloud browsers. Channel3 price data. Claude AI. And AG Grid."

**Delivery note:** List delivery — each name gets equal weight. Brief pause between each. "And AG Grid" with a slight finality. This should fit comfortably in ~8 seconds.

## Scene 8: THE CLOSE (2:03 — 2:22)

**Duration: 19 seconds | On screen: "PayPal makes the payment possible" text → "Canary makes sure it's deserved" text → Canary logo → GitHub URL**

> "PayPal makes the payment possible."

*(pause 3 seconds — text transitions on screen)*

> "Canary makes sure it's deserved."

*(silence for remaining ~10 seconds — logo and GitHub on screen, music resolves)*

**Delivery note:** These are the last words in the video. Slow down. "Possible" and "deserved" carry the most weight. After the second line, stop. Let the logo and music close it out. Do not add anything — the silence is the ending.

## Recording Notes

1. **Record each scene as a separate audio file** (Scene_3.wav, Scene_4.wav, etc.) so timing can be adjusted in post
2. **Format:** WAV, 44.1kHz or 48kHz, mono or stereo
3. **Environment:** Quiet room, close to mic, no echo
4. **Pace:** Slower than feels natural. Leave 1-second gaps between sentences
5. **No filler:** Zero "um", "uh", "so", "basically"
6. **Total speaking time:** ~85 seconds across scenes 3-8. The rest is text-on-screen and breathing room
7. **Emphasis guide:** Stress ONE word per sentence — it's bolded or noted above where it matters most
